# Σύστημα Διαχείρισης Βαρδιών

React/TypeScript frontend για ημερήσιες αναθέσεις Δ4, Δ5, ΕΜΚ και 24ωρης υπηρεσίας ΑΚΠ / ΑΥΜ. Το project δεν περιέχει backend ή βάση δεδομένων.

## Εκτέλεση

Απαιτείται Node.js 20.19+ ή 22.12+ και npm. Από τον φάκελο του project:

```bash
npm install
cp .env.example .env
npm run dev
```

Η εφαρμογή ανοίγει στη διεύθυνση που εμφανίζει το Vite. Χωρίς `.env`, η προεπιλογή είναι επίσης mock mode.

## Έλεγχοι και παραγωγή

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

Το `dist/` είναι στατικά αρχεία για Linux web server. Για React Router, ο web server πρέπει να επιστρέφει `index.html` για άγνωστα application paths όπως `/shifts`.

## Πραγματικό API

Στο `.env` ορίστε `VITE_API_MODE=real` και `VITE_API_BASE_URL=https://.../api`, κατόπιν κάντε νέο build. Τα προτεινόμενα endpoints και payloads είναι στο [BACKEND_INTEGRATION.md](BACKEND_INTEGRATION.md). Οι κλήσεις συγκεντρώνονται στο `src/services/http/`.

Για να διαβάσετε τη ροή του κώδικα, ξεκινήστε από τον «Χάρτη κώδικα» στο ίδιο έγγραφο. Τα ελληνικά σχόλια στους τύπους, στα services και στις σελίδες εξηγούν τα σημεία σύνδεσης και τις μετατροπές δεδομένων.

## Περιορισμοί demo

- Οι αναθέσεις αποθηκεύονται μόνο στο localStorage του ίδιου browser. Δεν συγχρονίζονται μεταξύ υπολογιστών.
- Η συνεδρία mock διατηρείται σε sessionStorage και δεν αποθηκεύεται password.
- Τα ονόματα, οι τύποι βαρδιών και οι αρχικές αναθέσεις είναι ενδεικτικά. Τα τελικά ωράρια και η οργανωτική λίστα θα δοθούν από το backend.
- Τα frontend permissions βελτιώνουν το UI, αλλά η πραγματική ασφάλεια απαιτεί έλεγχο στον server.
